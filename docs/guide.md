# 参数曲面光顺工具 (Parametric Surface Fairing)

对带小幅波纹的三次夹紧 B 样条张量积曲面，通过调整**自由控制变量**、在显式约束下
最小化**明确积分的弯曲 / 曲率变化能量**来光顺，同时保留指定边界、关键点和邻片公共边。

本工具不使用控制点均值滤波冒充曲率优化，也不通过平滑法线在视觉上隐藏波纹。均值滤波
仅作为带标签的对照基准 (`core/benchmark.py`)，所有曲率、反射条纹和能量都由解析导数
真实计算。

---

## 1. 图形入口（主要界面）

图形曲面编辑视窗是**主要界面**，命令行仅用于批处理。

```bash
# 推荐：通过脚本启动（会自动配置虚拟环境和系统库路径）
bash scripts/run_gui.sh

# 等价的手动方式
.venv/bin/python -m surface_fairing.gui
```

`scripts/run_gui.sh` 会切换到项目根目录、导出声明的测量尺度与系统库路径，
再以模块方式启动 `surface_fairing.gui`。没有图形显示时可用离屏平台自动核验
界面确实能构建并驱动内核：

```bash
LD_LIBRARY_PATH="$PWD/scratch/sysroot/usr/lib/aarch64-linux-gnu:$PWD/scratch/sysroot/lib/aarch64-linux-gnu" \
QT_QPA_PLATFORM=offscreen PYTHONPATH=. .venv/bin/python scratch/gui_smoke.py
# -> artifact 0/1/2 ... plots OK; SMOKE PASS
```

视窗功能：

1. 选择测试曲面（带扰动平面 / 带扰动弯曲面 / 需保留特征的过度光顺案例）；
2. 声明度量尺度、硬约束（边界、关键点、与 u0 冲突的偏移关键点）、邻环软锁定
   及其权重；
3. 选择弯曲能量类型（jerk / normal / thin_plate）、能量权重、附着权重与积分阶数；
4. 点击“运行光顺”，结果区显示真实计算的：
   - 光顺前后三维曲面；
   - 平均曲率变化场 `|dH|`；
   - 逐点位置残差场（采样距离，非控制点平均）；
   - 光顺前后反射条纹（基于解析法线的等照度线 isophote）；
   - 能量、高频波纹 RMS、曲率 RMS/峰值、硬约束误差、软约束松弛记录、
     可达切向角范围等数值。
5. “约束维护”面板：分析当前约束图，列出最小不可满足的子集、prune/relax 判定与
   软锁定的松弛边界；选中一项“剪除并重算”，由光顺内核重解，消息区给出该约束
   重新生效所需的条件（见第 7 节）；
6. 异常以对话框和消息区显式提示，不会被静默吞掉；
7. 可导出真实曲面 OBJ、控制点、约束维护结论与 JSON 报告。

窗口呈现的是**同一份曲面光顺内核**的输出：控件只收集度量、约束与权重，失败会在
对话框和消息区回传内核抛出的异常；没有任何“仅演示”的平行实现。

## 2. 可检查的数学对象

用户要求变量、积分域和约束方式都可检查，对应实现如下。

### 2.1 优化变量

- 唯一的自由变量是**控制点坐标向量** `x = (x0,y0,z0, x1,y1,z1, …)`，长度 `3*m`
  （`m = nu*nv` 个控制点）。
- 曲面 `S(u,v)=ΣΣ P_ij N_i(u) M_j(v)`，基函数及其 1/2/3 阶导数全部由
  Cox–de Boor / de Boor 递推**解析**给出 (`core/bspline.py: basis_table`)，
  并有有限差分测试覆盖。
- 控制点放在 Greville 横坐标上，使未扰动曲面精确再现平面 / 光滑穹顶。

### 2.2 积分域与积分方式

- 参数域 `[0,1]²`，按 B 样条**每个非零节点跨**布置 Gauss–Legendre 节点
  （阶数 2/3/4 可选，`core/energy.py: _gauss_nodes`），不遗漏也不重复节点跨。
- 面积元 `dA = |S_u × S_v| du·dv` 在**参考曲面**上冻结，使能量成为控制点的
  精确二次型 `E(x)=½xᵀHx−xᵀf+const`。
- 组装矩阵 `H`、节点数（`n_integration_points`）、归一化因子都写入报告，可直接检查。
- `direct_energy` 在光顺后的曲面上用其自身面积元**重新积分**，报告里的能量下降
  比例采用该真实值，而非冻结线性化的二次型值。

### 2.3 三种能量（bend mode）

| 模式 | 物理含义 | 优点 | 局限 |
|---|---|---|---|
| `jerk`（默认，弯曲面） | 三阶导数曲率变化能量 `S_uuu,S_uuv,S_uvv,S_vvv`（系数 1:3:3:1） | 强烈惩罚高频波纹、几乎不惩罚低频光滑穹顶，**保形** | 受边界约束与 B 样条可表示频率限制，对接近 Nyquist 的波纹去除幅度有限 |
| `normal`（默认，平面） | 二阶基本形式，二阶导数在解析参考法向上的投影 | 对近平面波纹去除接近彻底，且平面目标曲率本就为零、不会被“压平” | 冻结法向是小位移线性近似；在弯曲面上会把穹顶自身曲率也压低（实测平均曲率 RMS 1.97→1.04，相对光滑基底偏差由 0.00114 增至 0.00364，形状被改变） |
| `thin_plate`（对照） | 原始度量缩放二阶导数 | 常用代理，便于比较 | 在弯曲面上可能与实测曲率不一致 |

### 2.4 约束（`core/constraints.py`）

- **硬约束**（等式，进入约束零空间精确满足）：边界 `pin_edge`、邻环 `pin_ring`、
  单点 `pin_point`、以及通过基函数系数构成的真实线性约束 `pin_surface_point`
  （关键点保留，不是控制点平均）。
- **软约束**：带权重的邻环/棱线锁；与硬约束冲突时被松弛，并记录受影响控制环
  索引与最大几何偏离 (`soft_relaxation`)。
- 求解前做重复 DOF 检测和约束秩一致性检查，互斥硬约束直接抛 `InfeasibleConstraints`。

### 2.5 求解与防漂移（`core/solver.py`）

- 硬等式经 SVD 分解为特解 `z0` + 约束零空间正交基 `Z`，在自由坐标内解 QP。
- 目标含**数据附着项** `attachment_weight·½‖x−x_ref‖²`，固定约束不足时的
  刚体/参数化自由度，防止 Jacobian 塌缩造成的整体漂移与“虚假零能量”。
- 刚度矩阵先做**无量纲归一化**（除以对角均值，因子 `energy_scale` 记录在案），
  使附着权重在 jerk（原始量级 ~1e5）与 normal（~1e2）之间含义一致、可比、可调。
- 条件数、KKT 秩、ridge 均写入求解报告。

## 3. 声明的度量及其限制

- 度量为常系数尺度 `ds ≈ scale_u·du`、`dt ≈ scale_v·dv`
  （`core/bspline.py: Metric`），界面与 JSON 中以字符串显式声明。
- **限制 1**：常系数度量无法表达非均匀参数化。
- **限制 2**：二次型冻结参考面的面积元与（normal 模式的）法向，对弯曲面是
  小位移线性近似；因此最终结论以光顺后曲面上的 `direct_energy` 与实测曲率为准。
- **限制 3（B 样条可表示性 / 边界约束）**：四条边界硬锁定后，最小能量光顺对波纹
  振幅的降低存在数学上限，且该上限依赖控制网格分辨率与波纹频率。下表由
  `scripts/generate_doc_curves.py` 实际求解生成（`docs/curves.json`，normal 模式、
  附着权重 0.3、四条边全锁定），不是手填数字：

  | 网格 n×n | 波数 w | 高频波纹去除 | 直接能量下降 | 边界最大位移 |
  |---|---|---|---|---|
  | 9  | 1 | 62.4% | 91.2% | 4.7e-16 |
  | 9  | 2 | 78.3% | 97.6% | 4.7e-16 |
  | 9  | 3 | 94.1% | 99.6% | 4.7e-16 |
  | 13 | 3 | 85.1% | 97.9% | 4.7e-16 |
  | 17 | 3 | 81.9% | 96.8% | 4.7e-16 |
  | 21 | 3 | 71.8% | 92.7% | 4.7e-16 |

  旧版本文档曾写“normal 模式可去除约 98% 高频成分、加密网格有助提升可分性”，
  这两条都不可复现，已废弃。可复现的对照事实是：小网格（9×9）三波波纹去除 94.1%
  （不是 98%）；而在固定波数 w=3 下，网格从 9×9 加密到 21×21，去除比例由 94.1%
  降到 71.8%。其原因在于谱高频掩膜与可表示频谱随网格同时变化，**不能**据此断言
  “加密网格降低可分性”这一普遍结论；能确定的是**不能仅靠加密网格换来更高去除率**。
  jerk 模式在弯曲面仅锁边界时实测约去除三成波纹（见第 5 节），同样是可表示性上限。

  表内每一行都由一次真实光顺求解产生；网格、波数、附着权重与锁定边写死在生成
  脚本里，文档仅转录，不手改。

  以上限制由 `scripts/validate_contract.py` 的 `doc_curve_reproducible` 主张
  复核：它重新求解锚点并与 `docs/curves.json` 比对，文档数字若被手改或实现漂移
  都会导致主张失败。

## 4. 邻片拼接（`core/io_/stitch.py`）

- 拼接器先用 `SeamDeclaration` 声明公共边是否**不可移动**、该片是否被授权让步。
- 光顺器对每条边返回 `TangentialRange`：实际可达的跨边切向及其相对参考切向的
  角度包络 `angle_envelope_deg`。
- `negotiate` 仅在存在**被授权让步片**且其可达范围能容纳对方要求时判定兼容；
  两侧互斥且无授权片时返回 `compatible=False, yielding_patch=None`，
  局部让步绝不会落在未授权片上。
- `build_stitched_mesh` 对共边反向编号的一对曲面生成真实三角网格，自动反向对齐 B 片，
  并测量接缝裂口 `seam_gap` 与各自轮廓误差 `contour_error_a/b`。

## 5. 测试件与诚实的成功判据

`scripts/measure.py` 覆盖并保留以下案例（输出到 `output/measurements/`）：

- **带已知扰动平面**：normal 模式，能量 0.9643→0.0042（-99.6%），硬约束误差
  3.3e-16，边界零移动（4.7e-16），高频波纹 RMS 去除 94.1%；
- **带已知扰动弯曲面**：jerk 模式，能量 34364.9→24856.6（-27.7%），相对无扰动
  光滑穹顶基准的 RMS 偏差 0.00114→0.00099，中心高度 0.24518→0.24518
  （设计值 0.24518），即**去除波纹而不压平基底**，不以“变得更平”作为成功标准；
- **过度光顺案例（保留为失败案例）**：无关键点锁、小附着权重（0.02）时能量从
  175.95 降到 115.75（-34.2%），但局部凸包高度从 0.06746 被压到 0.05229；加关键点
  硬锁后高度精确回到 0.06746。这说明**降低能量不等于保留所有设计特征**——
  能量下降幅度更大的那个结果恰恰是失败的；
- **互斥约束案例（保留为失败案例）**：两片固定边位置冲突，接缝裂口
  `seam_gap=1.0012` 被检出，且必须经显式授权才能让步。

成功判据同时包含：约束误差、形状位移、相对真值基底的偏差、高频波纹 RMS、
曲率 RMS/峰值与反射条纹，而不是单一的“更平”或能量数字。边界位移与能量变化
由 `scripts/verify_maintenance.py` 自动核对（锁定的边必须停在 1e-9 内，内部必须
真被移动），并把逐条结论写入 `output/maintenance/maintenance_report.json`。

## 7. 约束资料维护：自约束图、剪除与松弛（`core/maintenance.py`）

求解器对一组无法同时满足的硬等式抛 `InfeasibleConstraints`。维护工具回答
**为什么不可行、该怎么办**，全部基于求解器消费的同一组线性约束行：

- **约束单元**：一次边锁定、一个关键点（三轴合成一个单元）、一条软环锁定各算
  一个节点。`units_from_hard` / `units_from_soft` 从活的约束集构造。
- **最小不可满足子集**：`find_minimal_unsatisfiable` 用删除滤波收缩一个不可行
  硬集，返回**极小**冲突子集——删掉其中任一成员，余下都可行。例如把关键点放在
  已被锁定的 u0 边上并要求 z=0.5，最小冲突恰为
  `['hard edge lock u0', 'key point S(0.000,0.500)']`，而不是四条边全卷进来。
- **prune 与 relax 的区分**（用同一套边界条件判定）：
  - 两个**硬**单元秩不相容 → `prune`。没有任何松弛量、权重或容差能同时满足，
    必须删掉其中一条（`recompute_after_removal` 删除后由光顺内核重解）。
  - **硬 + 软**环锁定 → `relax`。软锁定是罚项，不会让硬解失效；代价是该环
    要承受的几何偏离量。`relaxation_sweep` 扫描权重并报告可行边界：例如
    u0 软环在默认权重 `[1,10,100,1000]` 下最大偏离
    `0.010417, 0.004521, 0.000869, 9.6e-5` → 最小 9.6e-5，在 1e-3 容差内可行；
    权重越大偏离越小、越贴近锁定目标。
- **删除一项后重算并指出重新生效条件**：`recompute_after_removal` 删除某项、
  重跑真实光顺，得到剩余约束实际产生的控制向量 `x*`，再计算被删项的
  `A·x*`。只有当被删约束的目标改为该值、或冲突的另一方被删/被松弛时，它才能
  重新加上。对上面的关键点案例，重算后 u0 边把该点钉在 z≈0，被删关键点原目标
  z=0.5（gap 0.5），因此“重新生效条件”是把它改成 `[0, 0.5, 0]`，而不是直接加回。

图形视窗的“约束维护”面板与本节是同一实现：勾选“偏移关键点”制造冲突 →
`Analyze` 列出最小冲突与 prune/relax 判定 → 选一项 `Prune & recompute` 由内核重解
并显示反应条件；不勾冲突项时改勾软锁定，则显示松弛边界随权重的变化。

## 8. 光顺契约校验（`scripts/validate_contract.py`）

“契约校验”在这里指：**文档对光顺内核的主张由活代码重新推导，并与可执行证据
比对，而不是被信任**。它在一个干净目录里端到端运行，不读任何既有 `output/`
或 `scratch/` 文件、不依赖手改数据：

- 每条主张都调用公开光顺 API 在随附测试件上现场求解；
- **能量变化**（`direct_energy` 前/后，并用独立重积分交叉核对）与**边界残差**
  （逐边最大位移）都从真实解出的曲面测得；
- 结果写入新建目录（默认一个全新 `tempfile` 目录，因此从不依赖陈旧产物），
  并用 `.sha256` 记录报告摘要、用 `code_manifest_sha256` 记录所校验代码模块的
  哈希，供后续“陈旧材料”检测。

当前 7 条主张（净目录实测全部通过，见 `output/contract/contract_report.json`）：

| 主张 | 证据 |
|---|---|
| `locked_boundary_exact` | 锁定边逐点位移 ≤1e-9，硬约束误差 <1e-9 |
| `energy_decreases` | 直接重积分能量严格下降且与报告值一致 |
| `doc_curve_reproducible` | 重解锚点并与 `docs/curves.json` 逐位比对 |
| `curved_patch_retains_dome` | 中心高度贴近设计值、相对基准不更差、能量下降 |
| `over_fairing_is_failure_not_success` | 无锁结果能量更低但特征丢失，加固锁才保留 |
| `quadratic_matches_direct` | 三种模式的冻结二次型与直接积分相对误差 <1e-9 |
| `soft_relaxation_reported` | 软锁松弛有环索引与偏离，且硬残差不受影响 |

任何一条失败，脚本以非零码退出并列出具体失败主张——**不允许伪报**。文档里出现
的数字（含第 3 节曲线、第 5 节实测）均由这些脚本实际求解产生；实现若漂移，主张
即失败。

### 陈旧材料处置

旧提交里 `output/cli_plane/`、`output/cli_curved/` 的 `*_report.json` 与控制点/OBJ
是旧能量公式的产物：curved 报告写着能量 `3.455→1.932`、位置残差 `0.0552`、平均曲率
峰值 `2.875→6.265`（曲率反而增大），且缺少 `energy_normalization_scale` 与
`gauss_integration_points` 字段。当前代码在净目录重跑的对应值为能量
